Black hole simulator

A black hole simulation in C++ and OpenGL: gravitational lensing in 2D, then light traced along curved paths on the CPU and in a GPU compute shader. My working copy of kavan010's open-source project.

The write-up

What it is

Light near a black hole does not travel in straight lines. This simulation traces those bent paths, called geodesics, and draws what an observer would actually see.

How it works

Four programs that build on each other: 2D lensing, geodesics on the CPU, a ray tracer, and a GLSL compute shader that moves the geodesic maths onto the GPU. Built with CMake, GLFW, GLEW and GLM.

Credit

The code comes from kavan010's open-source black_hole project. I keep this copy to build, run and take apart.
