Multi-agent study system

Four agents that share one job: capture notes by voice, quiz me on them, find the topics I have not covered, and turn a lecture into a study guide. Built in one sitting for a Multi-App AI Agent Hackathon, where it got an honorable mention.

The write-up

4 parts

Why

Studying produced a pile of things that never spoke to each other: voice notes, lecture recordings and a vault of markdown. One agent doing all four jobs did none of them well, so I stopped asking it to.

What I built

A capture agent that files voice notes into the vault, a recall agent that quizzes me from them, a coverage agent that finds the gaps, and an agent that turns a lecture into a study guide. They share the vault as common ground instead of passing messages around, so I can replace any one of them without touching the others.

The guardrail

Every write from every agent passes through one fail-closed gate: each agent is scoped to its own folder, writes can only create or append, and every decision lands in an audit log. A dictated “delete every file” just becomes a note that says that. There is no delete to reach.

What is next

Splitting the coverage agent further, and finding a measure that shows whether the split actually helped.
