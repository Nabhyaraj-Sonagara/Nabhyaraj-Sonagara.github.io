A language model of about 30 million parameters, written from scratch in Python and NumPy. Attention, optimiser and tokeniser are all hand-written. It is small enough to run on a Raspberry Pi, and microcontrollers are the next target.

The write-up

Why

I could use a transformer long before I could explain one. A framework keeps the interesting parts behind an API, so I set one rule: Python and NumPy only, and every part hand-written until it trains.

What I built

A tokeniser, an attention block, a training loop and an optimiser, wired into a model of about 30 million parameters. The goal was never a benchmark score. It was a model I can read from end to end and still run on hardware that fits in a pocket.

What is next

Getting it onto a microcontroller. That needs quantization, which is how I came to write a paper about low-bit models in the first place.
