LanLink

An end-to-end encrypted messenger for Macs on the same Wi-Fi. No phone numbers, no accounts, no cloud: devices find each other over Bonjour and talk directly over TCP.

Platform
macOS 14+
Stack

The write-up

3 parts

What it is

Each device is known by its hardware MAC address. Messages travel directly between Macs on the same network, encrypted with Curve25519 and AES-256-GCM, and never touch a server.

What it does

Files up to 100 MB over the same encrypted session, with live progress on both ends. Typing indicators, unread badges, a Whisper Mode that blurs a message until the reader hovers over it, and signal bars that show the measured round-trip time to each peer.

When discovery fails

Strict networks block Bonjour, so you can add a device by its MAC address and IP. LanLink dials it directly on TCP port 42424 and runs the same encrypted handshake.
