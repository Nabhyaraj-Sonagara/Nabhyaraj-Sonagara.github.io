Agent Referendum

A notes vault built as a reference layer for AI agents. They read one brief first, so I never explain myself twice. It is part knowledge base and part operating system for the week.

The write-up

Why

Every new conversation started from zero. I was explaining my projects, my tools and my constraints again several times a week, and each explanation drifted. The agents were working from a version of me that was already out of date.

What I built

One vault with three layers: agent context, personal notes, and a life and work operating system. Agents enter through a single brief instead of searching folders. Every open question sits in one file, so the gaps are visible instead of silent.

What is next

Pulling in one more source, with a rule that keeps it current once it is there.
