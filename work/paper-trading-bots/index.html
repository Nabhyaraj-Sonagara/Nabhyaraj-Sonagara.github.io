Paper-trading bots

Trading bots trained and run on paper against Indian markets. No real money is involved, so the only thing at risk is my backtest. It is an excuse to learn how a strategy fails before a failure costs anything.

The write-up

3 parts

Why

I wanted to learn how a strategy fails, and the cheapest version of that lesson costs nothing. Paper trading keeps the feedback and removes the stakes, which makes it much easier to be honest about a bad run.

What I built

A harness as much as a bot. Every result is tied to the config that produced it, because a run I cannot reproduce is a run I learned nothing from.

What is next

The next strategy, and the one number that would convince me it works rather than that it fits the past.
