The write-up

2 parts

What it is

A system monitor that lives in the terminal. It draws hardware details, CPU load, memory use and sensor readings, and quits cleanly on q or Escape.

How it works

sysinfo gathers the numbers, ratatui draws them and crossterm handles the terminal. The loop is three steps: gather, draw, then wait half a second for a key.
